# Relatório de atualizações do site

Neste trabalho foram feitas algumas correções e melhorias nas páginas do site.

## O que foi corrigido

- Corrigi palavras que estavam com caracteres errados.
- Corrigi imagens que não apareciam nas notícias.
- Organizei as imagens da parte "Veja também".
- Cada recomendação agora usa a imagem da notícia correta.
- Corrigi alguns links entre as páginas.
- Troquei nomes de imagens que tinham acentos para evitar erros.

## O que foi adicionado

- Adicionei animação no botão do menu.
- Quando o menu abre, o ícone vira um X.
- Deixei o menu das notícias com o mesmo estilo da página inicial.
- Adicionei animação no botão da lupa.
- A lupa abre uma lista com outras notícias.
- O menu e a busca podem ser fechados clicando fora ou apertando Esc.
- Os botões receberam textos de acessibilidade.

## Organização do código

- Criei um CSS para as animações das páginas de notícias.
- Criei um JavaScript para controlar o menu e a lupa.
- Simplifiquei os comentários para facilitar a leitura do código.

## Testes realizados

- Verifiquei os caminhos das imagens.
- Verifiquei os links dos arquivos CSS e JavaScript.
- Testei a sintaxe dos arquivos JavaScript.
- Verifiquei se todas as páginas de notícias possuem os novos botões.
